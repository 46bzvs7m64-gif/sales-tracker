# 个人销售业绩管理系统

销售人员自用的客户跟进与业绩管理工具：管客户阶段、算漏斗和转化率，替代纸质表格和记忆。

## 功能

- 客户录入 / 阶段推进（线索 → 初步沟通 → 方案报价 → 商务谈判 → 成单 / 流失）
- 销售漏斗：各阶段客户数与占比
- 业绩指标：在途商机额、成交金额、成交客户数、赢单率、平均成交周期
- 数据存浏览器 localStorage，双击即用；支持导出 CSV

## 使用

双击 `index.html`。首次打开可点"载入演示数据"查看效果；正式使用前点"清空全部"录入自己的客户。同名客户再次保存即为阶段更新，自动记录创建日与更新日，用于计算成交周期。

## 面试可讲

- 销售管理的本质是漏斗管理：每个阶段的转化率暴露问题环节（线索多但报价少 → 需求挖掘能力弱）
- 赢单率、客单价、成交周期是复盘自己销售动作的三个核心指标
- 作为一线销售主动用数据工具管理自己的工作，是销售运营思维的起点
